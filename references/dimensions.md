# 11 维抽取指南

每个维度都使用同一条链：**观察 → 原文证据 → 机制 → 执行规则 → 适用范围 → 反例**。
可测的量和需要阅读判断的量分开标注。下表列的是分析任务，不代表脚本能自动计算全部指标。

| 维度 | 应当观察与提炼 | 必须防止的误判 |
|---|---|---|
| style 文风 | 情绪显露/留白、语体、描写密度、克制与夸饰的条件；定位句段比较 | 不能只贴“冷峻”“华丽”标签；悲伤剧情不等于悲伤文风 |
| syntax 句法 | 句长分布、长短切换、断句、标点、排比/省略/重复；比较相同场景类型 | 中文字符数不是词数；英文缩写、小数和引号使简单句界统计失真 |
| vocabulary 词汇 | 感官渠道、具体/抽象表达、意象簇、时代语域、动词选择 | 字符 n-gram 不是中文分词或词性；人名高频不等于词汇风格 |
| narrative 叙事 | 视角、限知、距离、顺序、时间跳转、信息隐藏、世界观投放 | 人物不知道的信息不应突然变成他的内心独白；不要混淆叙述者和作者 |
| character 人物 | 出场行为、目标/阻碍/选择、关系对照、弧线、行动与心理偏差 | 不用人物标签代替塑造机制；局部行为不足以证明全程性格 |
| dialogue 对白 | 角色句长、语气、礼貌、回避、攻击、潜台词、打断和关系变化 | 引号可能是书信、引用或特殊标记；不能把引号比例叫真正对白比例 |
| pacing 节奏 | 场景目标变化、信息释放、爆点与缓冲、对白/行动/描写/心理/旁白转换 | 句短不必然剧情快；语义分类比例必须人工标注并说明分母 |
| scene 场景 | 入场钩子、空间锚点、目标、冲突升级、信息增量、场景出口 | 场景模板不是事件摘要；同一章可有多个场景，一个场景也可能跨章 |
| suspense 悬念 | 埋设、读者/角色信息差、误导、延迟、回收、未兑现承诺 | 伏笔必须区分已证实/可能/未回收；不要把任意重复物件都算伏笔 |
| emotion 情绪 | 基线、触发、升降、峰值、转调、动作/物件的承载方式 | 情绪分数若为主观标注必须公开标尺；标点密度不是情绪识别 |
| theme_motif 主题母题 | 物件/地点/色彩/概念的重复与变形、人物选择承担的价值冲突 | 不凭单次意象宣布主题；指认象征时附反证与替代解释 |

## 角色语言指纹

为主要角色建立 characters 条目，notes 中记录：称谓与关系；常见语气和长度；对不同对象的变化；会回避什么；会不会自我解释；面对压力如何变形；允许的例外。每项重要判断应落到可引用规则，使用 rule_ids 连接，不靠印象造人物百科。

## 模板与禁区

模板 steps 要描述功能，例如“日常目标 → 异常细节 → 角色选择暴露偏差 → 信息升级 → 认知改变 → 新问题”，而不是移植来源具体事件。使用其支撑规则的 rule_ids 记录来源。

exclusions 保留机制层负约束，例如“在已建立限知视角的调查场景，不用角色内心直接告知尚未知晓的答案”。限定范围、说明例外；不要因为样本没有某种写法就断言作者禁止它。

## 脚本真实测量范围

metrics 只有 Unicode 字符数、非空白字符数、简易句界均值、空行段落数、成对引号片段数及引号内字符占比。ASCII 句号仅在后接空白/结尾时作为句界，缩写仍可能误切；引号匹配不完整时可能低估。没有分词、词性标注、情感分类、人物归因或真正语义对白比例。跨语言比较应先明确这些局限。
